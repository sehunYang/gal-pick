# gal-pick

디시인사이드 전문 갤러리의 글과 댓글을 근거로, 조건에 맞는 제품(또는 맛집·명소)을 골라 주는 [Aside](https://asidehq.com) 브라우저용 에이전트 스킬입니다.

```
/gal-pick 10만원대 무선 키보드이고 키 배열을 60배열입니다. 너무 시끄러우면 안됨.
```

추천마다 다음을 붙여 줍니다.

- **디시 원문 인용**: 고친 데 없는 원문 그대로이고, 갤러리·개념글 여부·추천·댓글 수와 글 링크가 함께 붙어요
- **조회 시점의 다나와 최저가**: 옵션별 가격, 상품 링크, 스펙 요약도 같이 나와요
- **조건 검증 결과**: 조건을 다 만족하는 제품이 없으면 가장 가까운 대안을 어긋나는 조건과 함께 보여 줘요

## 사용 예시

아래는 위 요청을 실제로 실행한 결과입니다(2026-10-15 조회). 조건을 다 만족하는 제품은 디시 근거가 없어서, 스킬 규칙대로 가장 가까운 대안을 어긋나는 조건과 함께 보여 줍니다. 마크다운 원본은 [examples/keyboard-60-silent.md](examples/keyboard-60-silent.md)에 있습니다.

![gal-pick 결과 예시](docs/images/result.png)

수집 단계에서 `galpick.run()`이 에이전트에게 돌려주는 요약입니다(실제 출력의 앞부분). 갤러리 선정, 수집 통계, 후보 집계, 문장 ID가 붙은 "문장 은행"으로 구성됩니다.

![galpick.run() 출력 예시](docs/images/run-brief.png)

## 동작 방식

```
요청 분석 ─▶ galpick.run()                                    ─▶ 후보 판단 ─▶ galpick.finish()          ─▶ 결과
             통합검색(정확도순) → 갤러리 3곳 자동 선정                         다나와 동시 조회(카테고리·
             → 목록 → 제목 관련도 우선 선별(판매글 제외)                        액세서리 필터, 옵션별 가격)
             → 본문·댓글 최대 30건 → 후보 토큰 집계                             + ID로 고른 인용을 원문·링크로 확정
             → 문장 은행(ID 부여) 반환
```

- **토큰 절약**: 디시·다나와 페이지를 스냅샷으로 읽지 않습니다. 헬퍼 스크립트가 필요한 부분만 잘라 짧은 텍스트로 돌려줘요. 도구 호출은 REPL 2회(`run`, `finish`)가 기본입니다.
- **인용 신뢰성**: 에이전트는 문장 ID만 고르고, 원문과 링크는 헬퍼가 채웁니다. 서로 다른 글쓴이의 문장은 이어 붙일 수 없고, 긴 댓글은 제품명이 들어간 2문장만 원문 그대로 발췌합니다.
- **관련도 우선**: 제목에 조건 단어가 있거나 질문·후기형인 글을 먼저 읽고, 그 안에서 개념글·추천·댓글 수로 가중합니다.

### 실측 (위 예시 조건 기준)

| 항목 | 값 |
|---|---|
| 수집(`run`) | 통합검색 150건 → 후보 글 213건 → 본문·댓글 24건, 약 58초 |
| `run` 출력 크기 | 약 4,300자 (글 1건당 약 200자) |
| 가격·인용 확정(`finish`) | 후보 4개, 약 10초 |
| 읽은 글 중 조건과 관련된 글 | 20건 중 19건 (같은 조건, 본문 20건 검증 실행) |

## 설치 (Aside)

`gal-pick` 폴더를 Aside 계정 스킬 폴더에 복사하면 모든 작업에서 쓸 수 있습니다.

```
<Aside 계정 루트>/skills/user/gal-pick/
├── SKILL.md
└── scripts/galpick.js
```

- Windows 예: `C:\Users\<사용자>\.aside\u\0\skills\user\gal-pick`
- 특정 프로젝트에서만 쓰려면 `<프로젝트>/.agents/skills/gal-pick`에 둡니다.
- `SKILL.md`의 `GP` 경로는 설치한 위치의 `scripts/galpick.js` 절대 경로로 바꾸면 가장 확실합니다.

## 사용법

Aside에서 아래처럼 요청합니다.

```
/gal-pick 20만원 이하 저소음 무접점 키보드
/gal-pick 디시에서 찾아줘: 5만원대 유선 게이밍 마우스, 가벼운 거
/gal-pick 성수동 혼밥하기 좋은 라멘집
/gal-pick 미니배열키보드갤에서만, 무선 40배열 키보드
```

- 예산은 이렇게 해석해요. "10만원대"는 100,000~199,999원, "10만원 이하"는 ~100,000원, "10만원 안팎"은 80,000~120,000원.
- 갤러리를 지정하면 그 갤러리에서만 찾습니다.
- 음식점·장소는 다나와 대신 웹 검색으로 영업 여부를 확인하고, 네이버 지도·카카오맵 링크를 붙입니다.

## 파일 구조

```
gal-pick/SKILL.md            에이전트 작업 지침 (조건 분석 → run → 판단 → finish → 출력)
gal-pick/scripts/galpick.js  수집·집계·다나와 조회·인용 확정 헬퍼 (Aside REPL에서 eval로 로드)
examples/                    실제 실행 결과 예시
docs/images/                 README 스크린샷
```

## 주의

- 일반 브라우징 수준의 접속만 합니다. 요청 사이에 0.8~1초 간격을 두고, 한 번 실행에 본문은 최대 30건만 읽습니다. robots.txt로 막힌 m.dcinside.com은 쓰지 않고, 캡차나 차단은 우회하지 않습니다. 차단이 감지되면 검색 스니펫만으로 진행하고 그 사실을 결과에 표시합니다.
- 인용은 출처 링크를 붙인 짧은 발췌입니다. 원문 저작권은 각 작성자에게 있습니다.
- 디시인사이드·다나와와 관계없는 비공식 도구입니다. 사이트 구조가 바뀌면 동작하지 않을 수 있습니다.
- 추천은 커뮤니티 의견을 모은 참고 자료입니다. 구매 전에 사양과 가격을 직접 확인하세요.
