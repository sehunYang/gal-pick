# gal-pick: 디시 갤러리 기반 추천

조건(예산·사양·취향·지역)에 맞는 후보를 전문 갤러리 글에서 찾아 **상위 3개**를 추천한다. 추천마다 **디시 원문 인용 3개**, 가격, 핵심 특징, 구매처(1순위 다나와)를 붙인다.

## 절대 규칙

1. **인용은 `finish()`가 돌려준 문장을 그대로 붙여 넣는다.** 직접 타이핑·요약·각색 금지. 비속어·혐오 표현만 `○`로 가린다.
2. **가격은 `finish()`의 다나와 조회값(조회 시점)만 쓴다.** 디시 글 속 가격은 쓰지 않는다.
3. 사용자가 갤러리를 지정하면 `gals`로 그 갤러리만 쓴다.
4. m.dcinside.com 금지, 캡차·차단 우회 금지, 헬퍼의 요청 간격(0.8~1초)과 본문 30건 한도를 바꾸지 않는다.
5. 본문을 못 읽고 검색 스니펫(`s#`)만 썼다면 결과 상단에 "본문·댓글 미확인, 검색 스니펫 기반"이라고 밝힌다.

## 토큰 규칙

- 디시·다나와 페이지에 `snapshot()`, 스크린샷, WebFetch를 쓰지 않는다. 헬퍼 반환 문자열만 `console.log`한다. `galpick.st`를 통째로 찍지 않는다.
- 도구 호출은 **REPL 2회**가 기본이다: ① `run` ② `finish`. 그다음 .md 저장 1회.
- 진행 상황은 한 줄로만 알린다.

## 1단계. 요청 분석 (도구 호출 없음)

확인 질문 없이 가정하고, 가정은 결과 상단에 적는다. 아래 `cfg`를 만든다.

| 키 | 내용 | 예 (10만원대 무선 60배열, 조용한 키보드) |
|---|---|---|
| `type` | `item` / `food` / `place` | `item` |
| `cat` | 갤러리 검색어 | `키보드` |
| `sq` | 통합검색어 2~3개. 여러 단어 가능. 하나는 넓게(`{분야} {핵심조건} 추천`) | `저소음 60배열`, `무선 60배열 추천`, `저소음 키보드 추천` |
| `gq` | 갤러리 내 검색어 최대 2개. **띄어쓰기 없는 한 단어**, 숫자만인 단어 금지 | `저소음`, `60배열` |
| `kw` | 조건 판별 키워드 | `저소음 조용 시끄 소음 무선 블루투스 60` |
| `brands` | 이 분야 브랜드·별칭(한글·영문). 후보 인식에 쓰인다 | `레오폴드 리얼포스 독거미 앱코 키크론 누피 nuphy 해피해킹 hhkb` |
| `prefer` | 조건에 가까운 세부 갤러리 이름 일부 | `미니배열`, `무접점` |
| `gals` | 사용자가 지정한 갤러리만 `[{gid, kind, name}]` | 생략 |

- 예산 해석: "10만원대" = 100,000~199,999 / "10만원 이하" = ~100,000 / "10만원 안팎" = 80,000~120,000.
- "너무 시끄러우면 안됨"은 강한 선호로 보고 청축·클릭축 옵션은 제외한다.
- 음식은 지역·맛집·음식 종류 갤러리, 장소는 여행·지역·캠핑·등산 갤러리를 `prefer`로 유도한다.

## 2단계. 수집 (REPL 1회, 약 50초)

```js
const GP = '<이 SKILL.md가 있는 폴더>/scripts/galpick.js'; // 절대 경로로 바꾼다. 예: <Aside 계정 루트>/skills/user/gal-pick/scripts/galpick.js
eval(await fs.readFile(GP, 'utf8')); galpick.reset();
await openTab('https://gall.dcinside.com/');
console.log(await galpick.run(page, { type: 'item', cat: '키보드', sq: [...], gq: [...], kw: [...], brands: [...], prefer: [...], max: 20 }));
```

헬퍼가 하는 일: 통합검색(정확도순) → 갤러리 3곳 자동 선정(거래·뒷담·배틀 등 제외) → 목록 → **제목 관련도 우선** 선별(판매·나눔글 제외) → 본문·댓글 최대 `max`건 → 후보 집계 → 요약 반환.

반환(`brief`) 읽는 법:
- `갤:` 선정 갤러리와 대안. 선정이 명백히 틀렸으면 `gals`를 지정해 `run`을 한 번 더 부른다. 이미 읽은 글은 다시 읽지 않는다.
- `후보:` `토큰 글수 가중 [근거ID]`. 토큰은 자동 추출이라 별칭(`660c`=`fc660c`)과 잡음이 섞인다. 정식 모델명으로 묶는 건 직접 한다.
- `[n] 갤ID 개념 ↑추천↓비추 댓수 날짜 제목` 아래에 문장 은행이 있다. `nbK`는 본문 K번째 문장, `ncK`는 K번째 댓글이다. 100자에서 잘려 보여도 `finish`는 전문을 쓴다.
- `진행 중: ... resume` 이면 `console.log(await galpick.resume(page))`를 부른다.
- `차단 감지` 또는 `본문 없음` 이면 `s#` 스니펫 ID로 진행한다(규칙 5).

## 3단계. 후보 판단 (도구 호출 없음)

- 문장 은행에서 후보별로 긍정·추천 / 중립 / 부정을 판단하고, 선호 조건(조용함 +, 시끄러움 −)을 반영한다.
- 순위는 `후보:`의 글수·가중치를 기본으로 하되, 서로 다른 글 2개 이상에서 긍정 언급된 후보를 우선한다.
- 상위 4~6개를 고르고, 후보마다 인용 ID 3개를 고른다. 가능하면 서로 다른 글, 조건 관련 평가를 우선한다.
  - `+`는 **같은 글 본문의 연속 문장만** 잇는다(예: `6b2+6b3`). 댓글끼리, 본문과 댓글은 잇지 않는다.

## 4단계. 가격·인용 확정 (REPL 1회)

```js
console.log(await galpick.finish([
  { name: '앱코 KN35BT', tok: ['kn35bt'], q: ['6b2+6b3', '15c3', '...'] },   // dn 생략 시 name으로 다나와 검색
  { name: '레오폴드 FC660C', dn: '레오폴드 FC660C', tok: ['fc660c', '660c'], q: [...] },
], { cat: '키보드', budget: [100000, 199999] }));
```

- `dn`은 다나와 검색어다. **브랜드+모델명만** 쓴다(축·색상을 붙이면 0건). 음식·장소는 `dn: null`.
- 반환: 후보별 다나와 상품명·최저가·pcode 링크·옵션별 가격(`예산X` 표시)·스펙, `근거 글: 개념글 n · 일반 n`, 그리고 메타·URL이 붙은 인용 블록. 인용은 2문장으로 자동 발췌된다.
- 스펙으로 필수 조건(무선, 배열·키 수 등)을 확인하고 어긋나면 제외한다. 옵션별 가격이 다르면 조건에 맞는 옵션의 가격·pcode를 쓴다.
- `다나와 가격비교 없음, 오픈마켓 최저`는 그 사실을 표기하고 쓴다. `결과 없음`이면 검색어를 바꿔 해당 후보만 `finish`를 다시 부르거나 다음 후보로 넘어간다.
- 음식점·장소는 WebSearch로 메뉴·가격·위치·운영과 폐업 여부를 확인하고, 링크는 네이버 지도 `https://map.naver.com/p/search/{상호 지역}`, 카카오맵 `https://map.kakao.com/?q={상호 지역}`을 쓴다.
- 조건 통과가 3개 미만이면 찾은 만큼 제시하고 가장 가까운 대안 1~2개와 어긋나는 조건을 적는다.

## 5단계. 결과 출력

```markdown
## gal-pick 결과: {요청 요약}
**조건** 무선 · 60배열 · 10~19.9만원 · 저소음 우선
**검색 갤러리** 미니배열 키보드(마이너) · 기계식키보드(마이너) · 무접점키보드(마이너)
{가정이나 수집 한계가 있으면 한 줄}

### 1위. {정확한 제품명}: {가격}원 (다나와 최저가, {조회일})
- **특징**: {조건 관련 핵심 특징 2~3개}
- **디시 평가**
  {finish가 준 인용 블록 3개를 그대로}
- **아쉬운 점**: {디시에서 나온 단점 1줄, 있으면}
- **구매처**: [다나와]({prod.danawa.com 링크}) · [네이버쇼핑](https://search.shopping.naver.com/search/all?query={제품명})

### 2위. ...
### 3위. ...

| 순위 | 제품 | 가격 | 핵심 특징 | 근거 글 |
|---|---|---|---|---|
| 1 | ... | ... | ... | 개념글 n · 일반 n |

<details><summary>수집 방법</summary>
갤러리별 검색어, 읽은 게시물 수, 조회 일시 (brief의 `수집:` 줄)
</details>
```

- 점수 숫자는 늘어놓지 않는다. WebSearch로 확인한 사실에는 Aside 인용 태그를 붙인다.
- 같은 내용을 artifacts 폴더에 `gal-pick_{카테고리}_{YYYYMMDD}.md`로 저장한다(사용자가 지정한 출력 폴더가 있으면 그곳).
- 끝나면 `closeTab(page)`.
